# FrameWeaver macOS - bản thử (chưa ký)

Bản build thử nghiệm cho macOS (Apple Silicon và Intel), đóng gói từ nhánh `build/macos-preview`
bằng `desktop/build-macos.py`.

- **Chưa ký bằng Apple Developer ID, chưa notarize.** macOS sẽ chặn (Gatekeeper) khi mở lần đầu -
  xem `HUONG-DAN-MACOS.html` đi kèm để biết cách mở.
- Nội dung giống bản Windows cùng thời điểm: Google Flow (extension), cài đặt ChatGPT (Codex CLI)
  và Muse (gateway muse2api) ngay trong ứng dụng, không cần Terminal.
- Không đóng gói tài khoản, cookie, khóa ký hay dữ liệu cá nhân nào.
